# 云端同步部署指南（Cloudflare Worker + KV）

全程免费，约 5 分钟。需要你亲自操作的只有 Cloudflare 账号内的几步（我无法登录你的账号）。

## 一、准备：安装 Node 并登录 Cloudflare

在项目根目录执行：

```bash
cd worker
pnpm install
npx wrangler login
```

浏览器会自动弹出 Cloudflare 授权页，点「Allow」即可（没有账号就用邮箱免费注册）。

## 二、创建 KV 数据库

```bash
npx wrangler kv namespace create BOOKMARKS
```

终端会输出类似：

```
[[kv_namespaces]]
binding = "BOOKMARKS"
id = "abcd1234xxxx"
```

把 `id` 的值复制，打开 `worker/wrangler.toml`，替换掉这一行里的占位文字：

```toml
id = "在这里粘贴你的 KV namespace id"
```

## 三、设置访问密码（二选一）

**方式 A（推荐）：用 Secret，密码不明文出现在文件里**

```bash
npx wrangler secret put AUTH_TOKEN
```

回车后输入你自己的密码（例如 `MyBook2026!`，记住它，等会儿网站里要填）。

> 方式 B：直接在 `wrangler.toml` 的 `[vars]` 下加一行（密码会随仓库保存，私有仓库可接受）：
>
> ```toml
> [vars]
> AUTH_TOKEN = "你的密码"
> ```

## 四、部署

```bash
npx wrangler deploy
```

成功后会显示 Worker 地址，形如：

```
https://my-bookmarks-api.<你的账号>.workers.dev
```

## 五、在书签站开启同步

1. 打开书签网站 → **设置 → 云端同步**
2. 填入：
   - Worker 地址：上面那串 https 网址
   - 访问密码：第三步设置的密码
   - 云端已有数据时的策略：**新部署的云端是空的，保持默认「智能合并」即可，会自动把当前本地 164 条上传**
3. 点「测试连接并开启同步」
4. 成功后状态显示「已同步」，手机/其他浏览器打开同一个网址、填同样的地址和密码，即可看到同一份数据

## 验证是否生效

- 任意设备新增/删除一条书签，另一台设备刷新后能看到
- 设置页「上次同步」时间会更新；断网时提示离线、改动暂存本地，恢复网络自动补传

## 常见问题

- **连接失败 401**：密码不对，重新 `wrangler secret put AUTH_TOKEN` 检查
- **国内访问 workers.dev 不稳定**：在 Cloudflare 给 Worker 绑定自有域名（Workers → 你的服务 → Settings → Domains & Routes），绑定后把网站里的 Worker 地址换成你的域名即可，数据不用迁移
- **想停止同步**：设置页「关闭云同步」，云端数据保留，网站回到纯本地模式
- **本地开发调试 Worker**：`npx wrangler dev`
